DATA REFRESH

Auto-update rereads your local MFAPIs database only, without provider requests. Fetch latest rates requests up to five SiftingIO snapshots using your private local server and counts toward API usage. It has a 3-minute cooldown; during market closures, quotes may remain stale.

◷

Transparent by design

Freshness is measured from the source observation time. If the upstream feed stops, the dashboard shows stale/unavailable rather than inventing an exchange rate.
